# Étape 1 : Définir les relations

** Voici les relations envisagées :
- 1 Cryptocurrency ↔ n MarketData : Une crypto-monnaie peut avoir plusieurs enregistrements de données de marché (historique).
- 1 User ↔ n Alerts : Un utilisateur peut configurer plusieurs alertes.
- 1 Cryptocurrency ↔ n Alerts : Une alerte concerne une crypto-monnaie spécifique.

# Étape 2 : Établir les attributs

** Cryptocurrency
- id (clé primaire, unique)
- name (nom de la crypto)
- symbol (symbole, ex. BTC, ETH)
- market_cap_rank (rang sur le marché)

** MarketData
- id (clé primaire, unique)
- crypto_id (clé étrangère vers Cryptocurrency)
- timestamp (date et heure des données)
- price_usd (prix en USD)
- volume_usd (volume d’échanges en USD)
- market_cap_usd (capitalisation)

** User
- id (clé primaire, unique)
- username (nom d'utilisateur)
- email
- token_hash
- password_hash

** Alerts
- id (clé primaire, unique)
- user_id (clé étrangère vers User)
- market_id (clé étrangère vers MarketData)
- price_threshold (seuil de prix pour l'alerte)
- variation_threshold (seuil de variation)
